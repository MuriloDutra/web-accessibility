Landmarks

Landmarks are the large regions of a page. A screen reader can list them and jump from one to the next, the same way it jumps between headings. A div with a class never shows up on that list.

The roles a screen reader announces are banner, navigation, main, contentinfo, region, article, and complementary. Those come from header, nav, main, footer, a named section, article, and aside.

Landmarks on this page

    Note: In NVDA and JAWS this list is a shortcut away. In VoiceOver it is the rotor, set to Landmarks. The button above does the same job. A header inside an article is not a second banner. A section with no name stays off the list.

    Header

    The band at the top of this page is a header. When it belongs to the page, and not to an article or a section, it is the banner. People use it to jump to the site name and the primary nav. One banner is enough.

    <header>
    <a href="/">Northwind Coffee</a>
    <nav>...</nav>
</header>
    <div class="header">
    <a href="/">Northwind Coffee</a>
</div>

    Nav

    A nav is a block of links for moving around the site or the page. The list at the top of this page is one. If you have more than one, name each so the landmark list can tell them apart.

    <nav aria-label="On this page">
    <ul>
        <li><a href="#stories">Stories</a></li>
    </ul>
</nav>
    <div class="nav">
    <a href="#stories">Stories</a>
</div>

    Note: A single “read more” link is not a nav. Save nav for a real group of links.

    Main

    There is one main on this page: everything between the top band and the bottom band. It is the primary content. A skip link points here so people can pass the nav.

    <main>
    <h1>Weekly menu</h1>
</main>
    <div id="main">
    <h1>Weekly menu</h1>
</div>

    Note: One main per page. A second one gives the landmark list two primary regions.

    Footer

    The band at the bottom of this page is a footer. When it belongs to the page, it is the contentinfo landmark: copyright, contact, and other site-wide notes. A footer inside an article belongs to that article, so it is not a second page footer.

    <footer>
    <p>© Northwind Coffee</p>
</footer>
    <div class="footer">
    <p>© Northwind Coffee</p>
</div>

    Section

    A section is a part of this page. It becomes a landmark only when it has a name. A heading inside is not enough. Open the landmark list: Hours is there, and Today’s roast is not. Today’s roast is still a heading.

    Named, so it is a landmark

    Hours

    Open until 6. This only makes sense beside the rest of this page.

    <section aria-labelledby="hours-heading">
    <h2 id="hours-heading">Hours</h2>
</section>

    No name, so it is not a landmark

    Today’s roast

    A section in the HTML, and missing from the landmark list.

    <section>
    <h2>Today’s roast</h2>
</section>

    Article

    An article is a piece that stands on its own. The story below is one. It has its own header, and that header is not a second banner. Open the landmark list and count the banners: there is still one.

    Note: A good test for an article is whether it would still make sense on its own, in another context. If you could move that part into a newsletter and it would still stand alone, it is probably an article. Hours only make sense beside the rest of this page, so they are a section.

    How to brew a cleaner cup

    Rinse the paper, use water just off the boil, and stop before the last bitter pour. Moved into a newsletter, this still stands on its own.

    <article>
    <header>
        <h2>How to brew a cleaner cup</h2>
    </header>
    <p>Rinse the paper, and stop before the last bitter pour.</p>
</article>

    Aside

    An aside is related to the page, and it is not the main point. A screen reader announces it as complementary, so people can jump to it or skip past it. The note below is about the brewing story. The story still makes sense without it.

    Related

    A grinder matters more than a fancy kettle.

    <aside aria-labelledby="related-heading">
    <h2 id="related-heading">Related</h2>
    <p>A grinder matters more than a fancy kettle.</p>
</aside>

    Note: Name each aside when there is more than one, so the landmark list can tell them apart.
