Keyboard accessibility

Tab index greater than 0

A tabindex greater than 0 puts an element in a custom Tab order. Positive values are visited first, from lowest to highest, before anything with tabindex="0" or no tabindex.

Buttons

Tab through these buttons. Visual order is First, Second, Third. Tab order is Third, Second, First, because of tabindex="3", 2, and 1.

Note: Positive tabindex is a bad practice. Keep the DOM in the order people should tab, and use CSS for layout. Another option is to reorder your DOM elements in the code.

<button tabindex="3">First</button>
<button tabindex="2">Second</button>
<button tabindex="1">Third</button>
