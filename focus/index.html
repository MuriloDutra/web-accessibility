Tab Index

How tabindex changes what Tab can reach.

Note: Only add tabindex to interactive controls, e.g. buttons, inputs, tabs, dropdowns, etc. Ask yourself: “Is this something the user is going to interact with?”

  • Tab index of −1 — skipped by Tab, focusable in code.
  • Tab index of 0 — adds a non-button to the Tab order.
  • Tab index greater than 0 — custom Tab order that ignores visual order.

Off-screen content

A hamburger menu whose links sit off the page until it opens. If those links stay in the document while hidden with only CSS position, Tab can still land on them and focus looks like it vanished.

Note: Hide a closed menu with hidden or display: none so it is not in the Tab order. Do not only slide it off-screen.
