Focus

Buttons with focus

Focus order should match the visual order. CSS can break that: a button can look last on the page while still being first in the tab sequence.

Regular focus

Tab through these buttons. Visual order and keyboard order stay aligned.

<button>Last Page</button>
<button>Reload</button>
<button>Next Page</button>

CSS affecting focus

float: right moves Last Page visually, but Tab still lands on it first.

<button style="float: right;">Last Page</button>
<button>Reload</button>
<button>Next Page</button>
