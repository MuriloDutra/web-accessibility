WAI-ARIA

aria-live

Text that changes after the page loads can be easy to miss. aria-live marks a region so a screen reader announces the new text. The value says how urgent that announcement is.

off, polite, assertive

Each box below is a live region that already exists on the page. The button only changes the text inside it.

off

Items: 0

polite

Results: 0

assertive

Warnings: 0

<p aria-live="off">Items: 1</p>
<p aria-live="polite">Results: 4</p>
<p aria-live="assertive">Warnings: 1</p>

off is the ordinary case: the text changes, and a screen reader stays quiet. polite waits until the person is done with what they are reading, then announces the update. assertive interrupts and announces it now.

Note: Put aria-live on the region before the text changes. Setting the attribute in the same moment as the new text is easy for a screen reader to miss. Save assertive for a message that needs attention immediately, such as an error.

Roles that bring a live region

role="status" is a polite live region. role="alert" is an assertive one. The ARIA examples page adds an alert when a connection check fails.

<div role="status">Results: 4</div>
<div role="alert">Could not connect!</div>

Note: A status is for a quiet update, such as a result count. An alert is for the interruption, such as “Could not connect!”.
