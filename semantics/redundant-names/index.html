Semantics

Redundant names

More text is not always better. If the icon sits next to a word the user can already hear, naming the icon again makes the control noisy.

Icon plus visible text

A search button that shows a magnifying glass and the word “Search” already has a name. An alt like “magnifying lens” makes a screen reader say something like “magnifying lens, Search, button”.

<button type="button">
    <svg aria-hidden="true">...</svg>
    Search
</button>
<button type="button">
    <img src="search.svg" alt="magnifying lens">
    Search
</button>

Note: Hide a decorative icon with aria-hidden="true" or alt="". Keep a name on the icon only when there is no visible text, like the hamburger in Screen Readers.
