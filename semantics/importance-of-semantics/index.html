Semantics

Importance of Semantics

By using good semantic HTML, you can make your life way easier with accessibility and having some default behavior for free, no need to implement it yourself.

Modal - <dialog> vs <div>

By using a <div> to create a modal, you have to manually manage the focus and the keyboard navigation, while with a <dialog> you have some default behavior for free. Like the ability to close the modal by pressing the Escape key and to lock the focus inside the modal.

Modal with <div>

This is a modal with a <div>.

<div id="div-modal" class="modal-backdrop">
    ...
</div>

Modal with <dialog>

This is a modal with a <dialog>.

<dialog id="dialog-modal">
    ...
</dialog>

openButton.addEventListener('click', () => {
    dialog.showModal();
});

Note: You must call showModal(). A plain <dialog> stays hidden until you do. That call also gives you the backdrop, the keyboard trap, and Escape to close.

Radio vs list item

Tab into each group, then try the arrow keys. Radios already move focus and the checked option. List items need roving tabindex: only one item is 0, the rest are -1, and you have to move that 0 yourself when the arrows are pressed.

TLDR: use radios, because they have everything you need out of the box.

<input type="radio" name="size">
