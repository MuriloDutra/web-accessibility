WAI-ARIA

First steps with ARIA

Custom checkbox

Note: This is just an example. In reality, you should use the proper HTML for a checkbox, e.g. <input type="checkbox"> instead of div.

<div class="checkbox checked">
    Receive promotional emails
</div>

The screen reader would read the code above as "Receive promotional emails". The user can't know it's a checkbox. Now let's fix this with WAI-ARIA:

<div
    class="checkbox checked"
    role="checkbox"
    aria-checked="true">
    Receive promotional emails
</div>

The screen reader would read the code above as "Receive promotional emails, Check Box checked" and now the user can know it's a checkbox

By using WAI-ARIA, you modify:

  • the accessibility tree

But you do NOT modify:

  • Element appearance
  • Element behavior
  • add focusability
  • add keyboard event handling
