Headings

Headings are a map of the page. People using a screen reader can list every heading and jump straight to a section. The level, from h1 to h6, says how those sections nest. The size of the text belongs in CSS.

Headings are how people move

A screen reader builds a list from the heading tags. That list works like a table of contents. A line that is only big stays off the list, so there is nothing to jump to.

The line below is a paragraph with a large font. Open the heading list and it will be missing.

    The level is the outline

    Use h1 for the page title, h2 for the main sections, and h3 for parts of a section. A sale line can be huge and still be a paragraph. Picking h1 because the type is large puts a second page title in the map.

    Sized with CSS

    <h1>Weekly menu</h1>
<h2>Breakfast</h2>
<p class="promo">20% off this week</p>

    20% off this week

    Sized with a heading tag

    <h1>20% off this week</h1>
<h1>Weekly menu</h1>
<h1>Breakfast</h1>

    The sale, the page, and the section are all titles. The heading list has no nesting, so there is no way to tell the banner from the content.

    Note: Keep a single h1, the title of the page. Everything else nests under it.

    Keep the levels in order

    Go one level at a time. An h3 belongs under an h2. Skipping from h2 to h4, or from h1 to h4, leaves a gap. The heading list can no longer show what belongs to what.

    Levels in order

    <h1>Weekly menu</h1>
<h2>Breakfast</h2>
<h3>Oatmeal</h3>
<h2>Dinner</h2>
    • h1 Weekly menu
    • h2 Breakfast
    • h3 Oatmeal
    • h2 Dinner

    Levels with a gap

    <h1>Weekly menu</h1>
<h4>Breakfast</h4>
<h6>Oatmeal</h6>
    • h1 Weekly menu
    • h4 Breakfast
    • h6 Oatmeal

    Note: A design can have many type sizes. You still only need as many heading levels as the content nests. The extra sizes are CSS classes.
