ARIA examples

Three patterns HTML has no tag for: a tree you can open and close, a button that is only an icon, and a message that shows up after the page has loaded.

Tree

A nested list is only a list. role="tree" and role="treeitem" tell assistive technology this is a tree. aria-expanded says whether a row is open. The rows inside a parent sit in a ul with role="group".

Note: The roles describe the tree. Opening a row is still script: set aria-expanded and show the group. Arrow keys move through the open rows. Right opens a row, Left closes it.

<ul role="tree">
    <li role="treeitem" aria-expanded="true" aria-labelledby="course-label">
        <span id="course-label">Accessibility course</span>
        <ul role="group">
            <li role="treeitem" aria-expanded="false" aria-labelledby="intro-label">
                <span id="intro-label">Introduction</span>
            </li>
            <li role="treeitem" aria-expanded="false" aria-labelledby="focus-label">
                <span id="focus-label">Focus</span>
            </li>
            <!-- ... -->
        </ul>
    </li>
</ul>

aria-labelledby points each row’s name at its own label. A screen reader can then say “Accessibility course, expanded” and move through the open rows. A collapsed row has aria-expanded="false", and its group stays hidden.

Image button

A button that contains only a drawing has an empty name. The accessibility tree records button and nothing else. aria-label="Filter" gives that button the name “Filter”.

Name: “”

Name: “Filter”

<button class="glyph">
    <div class="filter-glyph"></div>
</button>
<button class="glyph" aria-label="Filter">
    <div class="filter-glyph" aria-hidden="true"></div>
</button>

Note: aria-label sets the name in the accessibility tree. It does not add visible text. aria-hidden="true" keeps the icon out of that tree, so the name lives on the button.

Live update

Text added after the page loads can be easy to miss. role="alert" marks the new message as a live region, so a screen reader announces it.

<div role="alert">
    Could not connect!
</div>

Note: The alert is added when the check fails. A screen reader then says “Could not connect!” role="alert" is for a message that needs attention now.
