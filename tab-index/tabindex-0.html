Keyboard accessibility

Tab index of "0"

A tabindex of 0 makes an element focusable by the keyboard. Also can be programmatically focused using focus().

Images

Tab through the page. The first image cannot receive keyboard focus. The second can, because it has tabindex="0". Focus it and press Enter.

Note: If the image triggers an action, wrap it in a button (or a link). A bare img with tabindex="0" has no button role, so assistive technology may not treat it as a control.

<img src="hotel1.webp" alt="Resort swimming pool">
<img src="hotel2.webp" alt="Motel Sakura entrance" tabindex="0">
