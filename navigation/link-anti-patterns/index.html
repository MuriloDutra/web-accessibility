Navigation

Link Anti-patterns

Sometimes they might look like a link, but they are not. A span with a click handler, or a link with nowhere to go, only looks like navigation.

Looks like a link

A span can be painted to look like a link. It is still text. It is missing from the links list, and it cannot be focused with the keyboard.

I'm not a link

<span class="link" onclick="doSomething()">I'm not a link</span>

If the control does something on the page, use a button. Style it like a link if that is the look you want.

<button class="link" onclick="doSomething()" type="button">Now I'm a button</button>

A link used as a button

The other way around is just as confusing. An a with no real destination is not a link. href="#" does not count.

<a onclick="doSomething()">You might think this is a link, but it's not</a>
<a href="#" onclick="doSomething()">The href here is nonsensical</a>

Note: A link goes somewhere. A button does something here. Pick the element that matches the action.

Link and image

A link that only wraps an image has no name unless the image has alt text. The link or the alt should give enough context so the user can decide if they want to follow the link.

<a href="/">
    <img src="logo.jpg">
</a>
<a href="/">
    <img alt="Home" src="logo.jpg">
</a>

Say where the link goes

Avoid “Learn more” on its own. Be specific. The links list (used by screen readers) should not be “learn more”, then “learn more”, then “learn more” again.

<a href="https://www.example.com">Learn more</a>
<a href="https://www.example.com">Learn more about responsibly sourced coffee</a>

A real link

Now I'm a link

<a href="https://www.example.com">Now I'm a link</a>

Advantages of using a link:

  • It shows up in the links list for screen readers.
  • It can be focused with the keyboard.
  • It can be bookmarked.
