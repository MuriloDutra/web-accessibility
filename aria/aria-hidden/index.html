WAI-ARIA

aria-hidden

aria-hidden="true" removes an element, and everything inside it, from the accessibility tree. The element stays on screen.

Still on screen

Both lines below say “Saved”. The second one has aria-hidden="true", so a screen reader skips it.

In the accessibility tree

Saved

On screen only

Saved

<p>Saved</p>
<p aria-hidden="true">Saved</p>

A screen reader says “Saved” once. The second line is still painted on the page.

Note: Give aria-hidden an explicit value, true or false. Hiding a parent hides its descendants too. aria-hidden="false" on a child does not bring that child back.

Hidden from everyone

The hidden attribute removes the element from the screen and from the accessibility tree. display: none does the same. This paragraph is in the HTML, and it is not shown:

Saved

<p hidden>Saved</p>

Note: Use hidden when nobody should get the content. Use aria-hidden="true" when sighted people still need to see it, and assistive technology should skip it.

Decorative icons

An icon next to a word can add a second name. aria-hidden="true" keeps the drawing out of the accessibility tree, so the name is the visible word.

Name: “Checkmark Save”

Name: “Save”

<button>
    <img src="check.svg" alt="Checkmark">
    Save
</button>
<button>
    <img src="check.svg" alt="Checkmark" aria-hidden="true">
    Save
</button>

The first button can be announced “Checkmark, Save, button”. The second is “Save, button”.

Leave focusable controls alone

aria-hidden="true" does not remove an element from the Tab order. A button with that attribute can still take focus, and a screen reader may have nothing to say for it.

<button aria-hidden="true">Delete</button>
<button hidden>Delete</button>

Note: Hide a control you do not want people to use with hidden or disabled. Keep aria-hidden on decorative parts inside a control that already has a name.
